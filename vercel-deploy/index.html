Sessions

Every placed session asks for a start time — click the time on the grid to change it. A slot holds more than one session: use the + under it to add another. Drag a session to another slot to move it, click the × to remove it. Rest marks one slot as off; a day with nothing else booked reads as a rest day. “Study / other” blocks a slot without adding training hours. Every block is saved in this browser.
